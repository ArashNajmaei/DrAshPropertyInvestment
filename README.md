# Property Investment Decision Dashboard

## Windows
1. Install Python 3.11 or newer.
2. Extract this folder.
3. Double-click `run_app.bat`.

## Command line
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy online
Upload `app.py` and `requirements.txt` to GitHub, then deploy `app.py` through Streamlit Community Cloud.

The duty calculator is a general estimate. Use the official override for concessions, surcharges, unusual transactions, or an official assessment.
